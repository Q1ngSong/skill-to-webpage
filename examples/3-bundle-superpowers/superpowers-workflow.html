superpowers

obra/superpowers(v5.1.0)的 14 个 skill:一条从「想法 → 设计 → 计划 → 执行 → 收尾」的开发流水线,加上 TDD、调试、验证、代码审查等纪律型 skill,以及工作区隔离、并行分派两项工具型 skill。何时看这页:想知道做一件事要依次进哪些 skill、在哪分叉、哪里回头,或审计 skill 之间的引用关系。

主执行路径:using-superpowers → brainstorming → writing-plans → executing-plans / subagent-driven-development → finishing-a-development-branch;执行阶段把 TDD、代码审查、工作区隔离作为子 skill 调用;systematic-debugging 与 writing-skills 是独立入口,各自依赖 TDD 与 verification。跨 skill 的边全部来自各成员语义层(带行号引文、经校验);引用事实(cross-refs)零 LLM 抽取。
